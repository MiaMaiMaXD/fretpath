# FretPath — Requirements Traceability Matrix (RTM)

เวอร์ชัน 2.0 · จับคู่ requirement ทุกข้อในสเปกข้อ 2.1–2.2 กับ Test Case ใน `test-cases.md` (อัปเดตหลังแผนที่ 2 — หน้าเว็บผู้เรียน)

**ระดับ:** M = Must, S = Should, C = Could (MoSCoW ตามสเปกข้อ 2)

**สถานะ:**
- `ทำแล้ว (อัตโนมัติ)` = ทุก TC ที่ผูกอยู่มีเทสต์อัตโนมัติ (pgTAP และ/หรือ Playwright ที่ตั้งชื่อตามรหัส TC)
- `มี TC (บางส่วนยังไม่ automate)` = เขียน TC แล้ว แต่บางส่วนยังเป็น Manual (ระบุไว้ในคอลัมน์สถานะ)
- `ทำแล้วเฉพาะส่วน DB/สิทธิ์` = มีเทสต์อัตโนมัติเฉพาะชั้นฐานข้อมูล ส่วนหลังบ้านแอดมินรอแผนที่ 3
- `รอแผนที่ 3` = ยังไม่มี TC จะเขียนพร้อมการพัฒนาฟีเจอร์ในแผนที่ 3

## สรุปความครอบคลุม

- requirement ทั้งหมด 48 ข้อ (FR 41 ข้อ + NFR 7 ข้อ)
- มี TC แล้ว 37 ข้อ; ยังไม่มี TC 11 ข้อ — ทั้งหมดรอแผนที่ 3: FR-01.7, FR-01.8, FR-05.5, FR-07.2, FR-07.3, FR-07.7, FR-07.8, FR-07.9, NFR-05, NFR-06, NFR-07
- ระดับ M ทั้งหมด 42 ข้อ มี TC แล้ว 36 ข้อ; ที่ยังไม่มี 6 ข้อ (FR-07.2, FR-07.3, FR-07.7, NFR-05, NFR-06, NFR-07) เป็นงานแผนที่ 3 — เกณฑ์จบ "ทุก M มี TC" จะครบเมื่อเขียน TC ของแผนที่ 3 เสร็จ
- FR-01 (ข้อ 1.1–1.6), FR-02, FR-03, FR-04, FR-05 (ข้อ 5.1–5.4), FR-06, NFR-01 … NFR-04: ทุกข้อมี TC อย่างน้อย 1 ข้อ — ตรวจแล้ว ไม่พบข้อที่ขาด
- สถานะ (รวม 37 ข้อที่มี TC): ทำแล้ว (อัตโนมัติ) 21 ข้อ (FR-01.1–01.6, FR-02.1, FR-02.4, FR-03.1, FR-03.2, FR-03.4, FR-03.5, FR-04.2, FR-04.4, FR-04.6, FR-05.2, FR-05.4, FR-06.1, FR-06.2, FR-06.4, NFR-02) · ทำแล้วเฉพาะส่วน DB/สิทธิ์ 4 ข้อ (FR-07.1, FR-07.4, FR-07.5, FR-07.6) · มี TC แต่บางส่วนยังไม่ automate 12 ข้อ (FR-02.2, FR-02.3, FR-03.3, FR-04.1, FR-04.3, FR-04.5, FR-05.1, FR-05.3, FR-06.3, NFR-01, NFR-03, NFR-04)
- หมายเหตุ: TC ที่ผูกกับ FR-07.1, FR-07.4, FR-07.5, FR-07.6 เป็น TC ด้านความปลอดภัย/DB ที่เกิดจาก NFR-01 เท่านั้น ไม่ถือว่าครอบคลุมฟังก์ชันหลังบ้านทั้งข้อ จึงต้องเพิ่ม TC ของฟังก์ชันในแผนที่ 3
- ช่องว่างที่ยอมรับของแผนที่ 2 (ไม่มี E2E): กราฟคะแนนสูงสุดรายบท (FR-06.3), ช่องบทเรียนที่เกี่ยวข้องและปุ่มรีเซ็ตตัวจับเวลา (FR-05.1/05.3), วิดีโอ YouTube ที่ฝังจริง (FR-02.2), เสียงจริงของปุ่มดีดสาย (FR-02.3), Safari บน iPhone (NFR-03)
